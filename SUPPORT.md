# Support

For documentation corrections and reproducible, non-sensitive problems, open a [GitHub issue](https://github.com/hbwallet-team/HB-Desktop/issues) using the appropriate template.

When reporting a problem, include the operating system, application version (if known), expected behavior, actual behavior, and safe reproduction steps.

**Never publish** a recovery phrase, private key, wallet password, personal account information, or unredacted wallet backup.

This repository does not promise live support, recovery of lost funds, or assistance with private keys.
