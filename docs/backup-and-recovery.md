# Backup and recovery

Wallet recovery depends on the application's actual key-management design. This repository has not verified which backup or import methods HB Wallet Desktop supports.

## General precautions

- Never disclose a recovery phrase, private key, keystore password, or backup file to support staff or strangers.
- If the application displays recovery material, record it securely and offline, following the application's instructions.
- Do not save sensitive wallet material in issue reports, screenshots, public repositories, or chat messages.
- Before uninstalling or changing devices, confirm that you have a working, supported recovery method.
- Never test recovery by deleting your only accessible wallet or backup.

## If access is lost

Do not enter secret material into unofficial recovery websites. Check the documentation for your specific application version and seek help without sharing secrets.
