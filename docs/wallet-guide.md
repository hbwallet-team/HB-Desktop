# Wallet guide

## Overview

HB Wallet Desktop is presented as a desktop cryptocurrency wallet application for Windows and macOS. The exact supported assets, networks, account model, and transaction features have not yet been independently confirmed.

## Topics to document after application review

- Creating a wallet and importing an existing wallet
- Viewing addresses and balances
- Sending and receiving supported assets
- Transaction history and network fees
- Wallet settings and updates

Until those workflows are verified, rely on the application's actual prompts and avoid sending funds based on assumptions about supported networks.

Read [backup and recovery](backup-and-recovery.md) before using real funds.
