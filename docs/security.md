# Security guidance

- Download software only from a source you have independently verified.
- Check published installer hashes and digital signatures when available.
- Keep your operating system updated and use device-level protections.
- Verify receiving addresses and blockchain networks before transferring funds.
- Be cautious of impersonators offering wallet support or asking for recovery material.
- Treat unexpected requests for seed phrases or private keys as malicious.

See the repository [security policy](../SECURITY.md) for vulnerability reporting guidance.
