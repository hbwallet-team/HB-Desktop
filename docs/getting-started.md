# Getting started

This page is a safety-first checklist rather than a claim about specific application features.

1. Install the application from a verified source using the [installation guide](installation.md).
2. Check that the application and version match the software you intended to use.
3. If the application offers wallet creation or import, read each prompt carefully before proceeding.
4. If a recovery phrase is provided, store it offline and privately. Never send it to anyone or enter it into a website to obtain support.
5. Before transferring significant funds, verify the network, destination address, and transaction details independently.

For wallet-specific workflows, see the [wallet guide](wallet-guide.md).
