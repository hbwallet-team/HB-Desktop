# Releases and versioning

Published downloadable files, when available, appear on the [GitHub Releases page](https://github.com/hbwallet-team/HB-Desktop/releases).

The preserved tags `v3.3.6`, `v3.3.7`, and `v3.3.8` all reference the same historical Git commit. The tags alone do not establish that separate binaries or source snapshots are available for those versions.

Before attaching installers to a release, verify their provenance, distribution permissions, target operating systems, version labels, and file hashes. Do not label a binary as independently verified without performing that verification.

See [CHANGELOG.md](../CHANGELOG.md) for the documentation history.
