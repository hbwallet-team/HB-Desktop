# Troubleshooting

## Installer will not open

Confirm that the installer is intended for your operating system and has been obtained from a verified source. Check publisher signatures and file integrity where possible. Do not disable system security checks simply to run an unverified installer.

## Application will not start

Record the operating system version, application version, and any error message. Do not include private keys, recovery phrases, or other wallet secrets in screenshots or logs.

## Balance or transaction looks incorrect

Verify the selected network and compare transaction details with an independent, trusted blockchain explorer for that network. Do not resend a payment until its status is understood.

## Reporting an issue

See [SUPPORT.md](../SUPPORT.md) and use the GitHub issue templates for non-sensitive reports.
