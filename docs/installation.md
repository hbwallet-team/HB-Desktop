# Installation

## Before you install

1. Open the repository [Releases](https://github.com/hbwallet-team/HB-Desktop/releases) page.
2. Check whether a release actually contains a Windows or macOS installer. Tags alone are not download links.
3. Confirm that the installer comes from a source you trust. Check any published checksums or signatures independently, when available.
4. Back up any existing wallet data before upgrading or replacing an installation.

## Windows

If a verified Windows installer is available, download the file intended for your Windows version. Review the publisher and any operating-system warnings before running it. Do not bypass security warnings merely to complete an installation.

## macOS

If a verified macOS package is available, download the file intended for your Mac. Review the developer signature and macOS security warnings. Do not disable system protections to install an unverified application.

## After installation

Launch the application only after verifying the installer. Follow the application's actual on-screen instructions; wallet creation and import flows may vary by version.
