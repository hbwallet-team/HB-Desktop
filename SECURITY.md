# Security policy

## Reporting a vulnerability

If you discover a security issue, avoid posting exploit details or sensitive wallet information in a public issue. Use GitHub's private vulnerability reporting feature **if it is enabled** for this repository, or contact the repository maintainers through a verified private channel.

No security-response service-level agreement or dedicated security email address is currently published in this repository.

## Protect your secrets

Never share recovery phrases, private keys, wallet passwords, or unencrypted wallet backups with maintainers or support volunteers.

## Scope

This repository currently distributes documentation and may link to release assets. Source code and a reproducible build process are not available here, so no claim of independent security audit is made.
